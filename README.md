# Hotel Las Cañas — Demo visual

Demo estático del sitio web del **Hotel Las Cañas** (La Romana, República
Dominicana), publicado con GitHub Pages.

Muestra el diseño: página de inicio, galería, fotos de atracciones cercanas con
efecto 3D, secciones informativas, selector de tema y sitio multi-idioma (ES/EN).

> Esta es solo la vista estática. En la aplicación completa, las reservas se
> integran en tiempo real con la base de datos Firebird del hotel, con panel de
> administración, cuentas de cliente y reseñas de huéspedes.
